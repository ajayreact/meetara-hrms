# Stage 52 migration manifest

A fresh installation that must match the snapshots is not ready. The earliest mandatory stop is `0001_01_01_000000_create_users_table`, before any historical payload. Its unqualified `string()` columns are `varchar(191)` in both snapshots. The current framework default would create `varchar(255)`. This stage does not change that default.

The Stage 52 users-column candidate is the only new file that can be considered for a later disposable rehearsal, and only for its five explicit columns, and only after a separate approval. It is not in `database/migrations`.
